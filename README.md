# Regression & Time-Series Forecasting

Two applied machine-learning exercises: a logistic regression classifier built from scratch and a sliding-window model for gas-price forecasting.

## Notebook

`logistic-regression-and-gas-price-forecasting.ipynb` contains:

- A NumPy-based logistic regression implementation evaluated on the breast-cancer dataset, with **96.5% recorded accuracy**.
- A 40-day sliding-window forecasting workflow that predicts future gas prices from prior observations.

## Run it

Open the notebook in Google Colab or Jupyter and run the cells in order. To rerun the forecasting section, upload the dataset named `40-Day_Gas_Price_Dataset.csv` into the session first.

## Skills demonstrated

`Python` · `NumPy` · `Pandas` · `Logistic Regression` · `Time-Series Forecasting` · `Feature Windows`
